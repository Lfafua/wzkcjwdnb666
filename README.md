# 灰线 1917

原创一战像素风网页策略游戏。用步兵、重机枪、迫击炮、早期坦克和炮兵弹幕夺取阵地。白桦隘口、淹没的农庄、黑脊高地三场战役各有不同的哨点布局与敌军增援。占领哨点可加快补给。

## 如何游玩

在仓库点击 **Code → Download ZIP**，解压后用浏览器打开根目录的 `index.html`。也可以打开仓库里的 [index.html](./index.html)，使用文件页面的下载按钮单独下载。游戏包含在一个 HTML 文件中，下载后可离线运行。

- **手机**：点路线和兵种卡部署。竖屏时军令在战场下方，横屏时移到右侧。
- **全屏**：点右上角 **全屏**，再点 **退出全屏** 返回。浏览器不提供原生全屏时，游戏会扩展到当前页面的可视区域，浏览器工具栏可能仍然显示。
- **电脑**：Q / W / E 选路线，1–5 下令，空格暂停，F 全屏。
- 关卡解锁进度由当前浏览器保存。浏览器限制本地文件存储时，进度只在本次打开期间有效。
