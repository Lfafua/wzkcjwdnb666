# 灰线 1917 · 战壕指挥所

[直接在线游玩](https://lfafua.github.io/wzkcjwdnb666/)

一战题材像素即时战术游戏。协约国及其参战伙伴包括英国、法国、俄国、意大利与美国，同盟国可选德国和奥匈。每国有七个军械条目及一支专属分队。军械册提供史实参数、馆藏或参考资料，以及独立的游戏数值。

双方单位默认向对方指挥所自由推进，可在战场上绕开岩石和断墙。占住三个前沿据点可加快补给。废墟、树林、弹坑和壕沟影响防护，浅水和铁丝网影响速度。可选择白桦壕线、被淹没的渡口、石灰岩高地，以及三档 AI 难度。

- **单选与框选**：点击己方单位，或拖框圈选部队。也可用「全选」。
- **下令**：选择「移动」后点地图。用「固守」停下，或点地图指定固守点。用「冲锋」恢复自动推进。电脑也可右键指定移动位置。
- **手机**：可横屏游玩。右上角支持全屏，战场支持双指缩放、平移和缩放按钮。
- **键盘**：Q 全选、E 移动、R 固守、T 冲锋、1–7 调派增援、空格暂停、F 全屏。

地图是虚构交战地点。装备混编覆盖 1914–1918 年各时期，国别加成是基于史实背景设计的平衡值。

本地运行可下载仓库后打开根目录的 `index.html`。请保留 `style.css`、`data.js`、`terrain.js` 与 `game.js`，游戏无第三方运行依赖。
